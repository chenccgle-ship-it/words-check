# 课堂界面设计

## 方向

采用 design-taste-frontend 的 Type and nothing else 方向，seed 2032758441。课堂真实材料是被抽查的五个词，主画面由词汇本身、清晰的留白与固定的判分位置构成。

该技能主要面向展示网站。本项目是教学操作界面，依据用户明确的课堂大屏需求保留五张功能卡片、词序和单屏结构。没有添加网站宣传段落、摄影素材或持续动画。

## 配色与字号

调色板进行了一次重抽，原因是初始橙色大色块不适合课堂投屏。重抽的粉色同样未用于产品界面，最终按课堂黑板材料映射为深绿背景、粉笔白题目区、浅绿主要操作，以及红绿判分反馈。

字号使用离线可用的 Segoe UI / 微软雅黑。1920 像素宽度下英文提示最高约 58px，中文答案最高约 40px。长内容自动缩小以适应卡片，英文优先保持两行。只有短暂的揭晓和按压反馈，并支持系统减少动画设置。

## 验证

源码风格检查为 0 FAIL / 0 WARN。真实浏览器检查覆盖 1920、1440、768、390 像素宽度，对比度、溢出、字号与换行检查为 0 FAIL / 0 WARN。

检查明确豁免了展示网站专用指标：四张摄影图片、视频、八个运动元素、单个营销焦点及重复图标卡片。原因是课堂工具需要五个稳定、可重复操作的单词控件，避免在讲课时持续分散注意力。真实界面没有用 data-ui 包裹整页来跳过检查。

项目不使用找到的照片、视频或虚构内容。截图里的词汇来自默认九年级词库。

Top three problems:

3. 揭晓后额外出现判分栏导致版面变化：始终预留固定判分行。
