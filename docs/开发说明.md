# 开发说明

## 架构

应用使用原生浏览器技术，SheetJS 0.18.5 随源码提供，不使用 CDN。Node.js 仅运行静态本地服务，不接收词库或学生答案。

`app/default-words.js` 从 `data/yilin-grade9-lower.json` 生成。应用首次初始化时为每条词汇生成 ID，并将累计正确、错误次数设为零。以后读取浏览器本地数据，不在每次启动时重新初始化。

存储键为 `words-check-nine-lower-v1`。服务默认地址固定为 `http://127.0.0.1:18765/`，浏览器存储属于此 origin。更换端口、主机名或浏览器会得到独立的数据区。

每轮抽查的卡片是持久词条的副本，保留词条 ID。判分先撤回卡片旧结果，再累加新结果；相同结果重复点击不改变累计统计。翻页只改变可见范围，不重新抽取。

## 运行和检查

```sh
npm start
npm test
```

不需要 `npm install`。Node.js 22+ 即可运行。若不希望启动浏览器，可使用：

```sh
node scripts/server.cjs --no-browser
```

测试使用隔离的浏览器数据替身和真实的离线 SheetJS 组件，覆盖默认词库数量、零初始统计、重复判分、改判、撤销、分页、统计保存、Excel 往返、课程删除、窄屏分页与键盘翻页。它不替代真实浏览器的视觉与系统启动检查。

## 修改默认词库

编辑 `data/yilin-grade9-lower.json` 后运行：

```sh
npm run generate
npm test
```

每个课程包含 `name` 和 `words`，每条词汇包含 `en`、`cn`、`pos`、`note`。不要提交个人浏览器数据或学生检测记录。

默认词库变化不会自动覆盖用户已有的本地词库，以免丢失记录。需通过导入或有明确数据迁移规则的版本更新处理。

## 构建 Windows 便携版

开发运行支持 Node.js 22+。便携包当前固定使用 Windows x64 的 Node.js 24.19.0，以匹配随包提供的运行环境许可。使用该版本运行：

```sh
npm run build:portable
```

构建脚本复制当前 Node.js 可执行文件、离线页面、默认 Excel、许可和说明，生成相对路径启动脚本及快捷方式，再压缩到 `dist/`。

`runtime/node.exe` 和 ZIP 不进入源码 Git 历史。发布时，把生成的 ZIP 上传到 GitHub Release 的 Assets。

启动脚本以隐藏窗口运行本地服务，服务就绪后打开默认浏览器。已运行时复用同一服务。停止脚本仅向本机、具有正确应用标识的服务发送停止请求。

## 发布前检查

1. 运行自动化检查。
2. 在浏览器检查普通窗口和全屏布局、三个检测模式及分页。
3. 在全新浏览器数据区检查四课程、192 词、零统计。
4. 测试 ZIP 完整解压后的双击启动、停止与离线 Excel 导入导出。
5. 更新 CHANGELOG 和版本号，再建立 Release。
