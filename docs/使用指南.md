# 使用指南

## 第一次打开

从 Releases 下载 Windows x64 ZIP，右键选择“全部解压”。进入 `words check` 文件夹，双击“启动 words check”快捷方式。

请保留整个文件夹。如果快捷方式不可用，双击 `启动 words check.vbs`。不要直接双击 `app/index.html`，应用应通过本地服务打开。

软件会在本机 `127.0.0.1:18765` 提供页面，只监听本机，不对局域网开放。重复双击启动会复用已经运行的服务。

## 一次课堂抽查

1. 点击“选择课程”，选择一个或多个单元，确认并抽取。
2. 设置抽取数量和检测方式，再点击“随机抽取”。
3. 学生口头回答，老师判断：左侧 ✓ 为答对，右侧 ✕ 为答错。
4. 点击后揭晓答案，卡片显示对应的绿 / 红背景。
5. 抽取超过五个词时，用“下一页”继续；返回上一页保留本轮判分状态。

桌面大屏每页最多五个词，窄屏手机每页一个词。可使用键盘 ← / → 翻页；输入框或管理弹窗打开时保留正常键盘操作。

看英文说中文模式默认展示英文；看中文说英文模式默认展示中文。自由模式可分别点击中英文揭晓，再判分。

重复点击同一个判分按钮不会增加次数。改判会撤回此前计数并计入新结果。点击 ↶ 可撤销该卡本轮判断。只揭晓答案不计分。

## 添加与导入

打开“管理词库”，可以添加单词、导入 Excel、下载模板，或搜索和编辑已有词汇。

Excel 每页一个课程，表头在第一行，英文、中文分别放在前两列。多个释义放在同一单元格。同一课程中，英文忽略大小写、中文相同的条目会视为重复。相同英文配不同释义可分别保留。

上传后先检查课程数量与词数，再确认导入。同名课程会追加新词，不替换已有单词或统计。

## 备份和换电脑

在“管理词库”点击“导出词库与统计”，得到新的 Excel 文件。应用不会修改原来的上传文件。

换电脑时，先启动软件，再删除新电脑上与备份同名的默认课程，最后导入备份。这样可恢复备份中的累计统计。删除前请确认新电脑的这些课程没有需要保留的记录。

同一台电脑请保持使用同一个浏览器，避免无痕窗口。清除浏览器数据之前务必导出备份。

## 清零和删除

“管理词库 → 清零统计”会清零所有课程的错误、正确及检测次数，保留单词。

“选择课程 → 删除”会删除整个课程、该课程所有词汇及统计；删除操作无法在应用内撤销。可以通过事先导出的 Excel 备份恢复。

## 退出与再次启动

关闭浏览器页面即可结束抽查。若要停止后台服务，双击 `停止 words check.vbs`。下次继续双击启动快捷方式。

如果页面无法打开，请先确认已经完整解压且没有移动 `runtime` 文件夹，然后重新启动。若生成了 `启动错误.txt`，可将其中错误内容附在 Issue 中。
